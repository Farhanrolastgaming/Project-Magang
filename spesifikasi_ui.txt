1. SKEMA WARNA & TIPOGRAFI (DESIGN SYSTEM)
--------------------------------------------------------------------------------
* Palette Warna Utama:
  - Primary Color    : #1E3A8A (Navy Blue - Navbar, Header, Tombol Utama)
  - Secondary Color  : #3B82F6 (Royal Blue - Highlight, Focus State, Hover)
  - Accent Color     : #10B981 (Emerald Green - Status Aktif, Tombol Sukses)
  - Neutral Dark     : #1F2937 (Charcoal - Teks Utama)
  - Neutral Light    : #F3F4F6 (Cool Gray - Background Aplikasi)
  - Card / Surface   : #FFFFFF (White - Latar Belakang Komponen/Kartu)
  - Status Alert     : 
    * Success : #059669 (Hijau)
    * Warning : #D97706 (Kuning/Orange)
    * Danger  : #DC2626 (Merah)

* Tipografi:
  - Font Family : Inter / Roboto / Sans-serif
  - Heading 1   : Bold, 24px
  - Heading 2   : SemiBold, 18px
  - Subheading  : Medium, 14px
  - Body Text   : Regular, 14px
  - Small / Caption : Regular, 12px

4. KOMPONEN UTAMA & INTERAKSI (UI COMPONENTS)
--------------------------------------------------------------------------------
* Tombol (Buttons):
  - Primary Button   : Solid Background #1E3A8A, Teks Putih, Rounded 6px.
  - Secondary Button : Border #1E3A8A, Background Transparan, Teks #1E3A8A.
  - Danger Button    : Solid Background #DC2626, Teks Putih.

* Form Input:
  - Border Gray (#D1D5DB), Height 40px, Padding 10px.
  - Focus State: Border Blue (#3B82F6), Ring Outline Soft Blue.
  - Error State: Border Red (#DC2626) + Pesan Teks Merah di bawah input.

* Modal / Pop-up Dialog:
  - Semi-transparent Overlay (#000000 50% Opacity).
  - Box Modal di tengah layar dengan opsi header, body, dan footer tombol aksi.

* Notification Toast:
  - Position: Top-Right.
  - Auto-dismiss setelah 3-5 detik.
